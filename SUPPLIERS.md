## Дані, які просимо у кожного постачальника

Обов'язково:

- SKU постачальника
- EAN/штрихкод
- назва
- бренд
- країна виробництва
- вага/об'єм
- закупівельна ціна
- рекомендована роздрібна ціна, якщо є
- залишок
- коробковість
- мінімальне замовлення
- термін придатності / мінімальний залишковий термін
- URL або файл фото
- склад та алергени
- українське маркування / дані імпортера

Бажано:

- XML/YML/CSV/XLSX feed
- API
- дата останнього оновлення залишку
- акційна закупівельна ціна
- рекомендована націнка

## Технічний імпорт прайсів

У репозиторії є:

- `data/supplier-feed-template.csv` — наш бажаний формат.
- `scripts/import-supplier-feed.mjs` — нормалізатор CSV/XLSX.
- команда: `npm run import:supplier -- path/to/feed.xlsx supplier-id`.
- `data/supplier-contacts.json` — статус контактів.

Нормалізатор не публікує товар автоматично. Позиція має отримати підтверджену закупівельну ціну та позитивний залишок перед відкриттям продажу.
